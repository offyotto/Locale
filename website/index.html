Features

For people who keep moving between networks.

01

Named contexts

Create contexts for client VPNs, local APIs, lab networks, and short-lived debug setups.

02

Safe hosts apply

Enabled entries are written through macOS administrator authorization, then DNS cache is flushed.

03

Automatic backups

Locale stores a backup before every write so you can inspect or recover previous hosts content.

04

Menu bar switching

Keep context switching one click away without opening the main window.

05

Import and export

Move contexts between Macs or keep a JSON backup alongside project notes.

06

Local by design

No telemetry, accounts, analytics, sync service, or cloud dependency.

Safety model

It edits the hosts file like a careful guest.

Locale never rewrites your whole /etc/hosts file. It removes and replaces only its own marked block, leaving everything else alone.

# BEGIN LOCALE MANAGED HOSTS
10.8.0.12   api.client.local
10.8.0.23   db.client.local
127.0.0.1   local.test
# END LOCALE MANAGED HOSTS

Install

Download, unzip, apply a context.

Locale is distributed as a notarized Developer ID app because the core feature needs privileged hosts-file writes.

Download Locale Release notes
  1. 1

    Download Locale-notarized.zip from GitHub Releases.

  2. 2

    Open Locale.app and create your first context.

  3. 3

    Add host entries, then apply with macOS administrator authorization.

Why not the Mac App Store?

Locale needs privileged access to update /etc/hosts. That makes Developer ID notarized distribution the honest fit for the real app, while keeping Gatekeeper validation intact.
